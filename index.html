Procedural 3D Voxel Engine

This 3D Voxel Engine was developed in PyCharm using Pygame and Python. It procedurally synthesizes vast voxel landscapes with colorful, multi-layered elevation contours, dynamic camera navigation, and real-time mesh rendering.

To create this engine, I followed the comprehensive YouTube tutorial "Creating a Voxel Engine (like Minecraft) from Scratch in Python" by Coder Space, learning the core mathematics behind procedural heightmaps, voxel chunk structures, and high-performance graphics loops.
